# 🚀 BuizTrack

> A modern financial SaaS web application built for seamless business expense and cash flow tracking, developed for **HackGlobal 2026**.

---

## 🌟 Features

* **Financial Tracking:** Monitor business expenses, revenue, and cash flow in real-time.
* **Modern UI/UX:** Clean asynchronous UI enhancements including dynamic loading spinners and dotted loaders for login, signup, and logout actions.
* **Cloud-Ready:** Fully containerized with Docker for effortless deployment on cloud infrastructure.

---

## 🛠️ Tech Stack

* **Frontend / Backend:** Modern web technologies & APIs
* **Deployment:** Docker, Vultr Cloud Ubuntu Server
* **Hosting:** Live demo available at [BuizTrack Live](https://buiztrackp.edgeone.dev)
